# Nocturne

Nocturne is a horror-focused movie discovery app built with React, Vite, React Router, and the TMDB API.

## Features

- Browse curated horror movie categories
- Search for movies
- View dynamic movie detail pages
- Watch trailers
- Save movies to My List
- Persist favorites with localStorage
- View cast and crew information
- Responsive design for desktop, tablet, and mobile

## Tech Stack

- React
- Vite
- JavaScript
- React Router
- TMDB API
- CSS
- localStorage

## Project Goals

This project was built to practice API integration, routing, component architecture, state management, responsive design, and persistent user data in React.
